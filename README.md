# CarGuessr 🚗

**CarGuessr** é um jogo de adivinhação de carros inspirado no Wordle. A cada round, uma foto de veículo é revelada progressivamente — e você tem até 5 tentativas para identificar o modelo correto.

🔗 **[Jogue agora → matheuskid.github.io/car-guessr](https://matheuskid.github.io/car-guessr/)**

## Como Jogar

A cada tentativa, selecione:

1. **País de origem** da montadora
2. **Marca** (filtrada pelo país selecionado)
3. **Modelo** (filtrado pela marca)

Quanto menos tentativas usar, mais pontos você ganha. Após todos os rounds, um resumo exibe sua pontuação total e a compara com seu melhor resultado pessoal.

### Feedback por Cores

| Cor | Significado |
|---|---|
| 🟩 Verde | Campo correto |
| 🟨 Amarelo | Parcialmente correto (ex: modelo certo, geração errada) |
| ⬜ Cinza | Incorreto |

## Modos de Jogo

| Modo | Descrição |
|---|---|
| **Desafio Diário** | Um carro novo a cada 24h |
| **Modo Livre** | Partida sem restrição |
| **Fácil** | Carros populares e conhecidos |
| **Médio** | Mix de clássicos e modernos |
| **Difícil** | Modelos raros e protótipos |
